## Baseline meaning

This candidate acknowledges the method repository's completed third-handshake
disposition for the immutable ARINC v4.3 release. It does not revise the
Candidate GVS Core, rewrite v4.3, change any mapping relation or row status,
establish Project Configuration, execute the instance-evaluation protocol, or
produce protocol-conformance, certification, authority-acceptance, scalability,
or RQ8-closure claims.

The MethodDefinitionCommit identifies the method contract. The separate
MethodCompatibilityDispositionCommit identifies the reviewed disposition. The
ARINC v4.3 release commit identifies the assessed instance content. These three
identities and the future v4.3.1 acknowledgement merge are non-substitutable.

## Activation rule

The baseline becomes effective only when an independent natural-person review
approves an unchanged final PR head and an ordinary two-parent merge completes
with that head as its second parent. Repository CI must succeed after merge.
Only then may annotated tag `v4.3.1` be created at the merge commit. Until that
event, this document is a candidate record and `v4.3` remains the released
baseline.

The method repository receives no new baseline or tag from this operation.

## 基线含义

本候选确认方法仓库针对不可变 ARINC v4.3 发布完成的第三次握手处置。它不修订 Candidate
GVS Core，不改写 v4.3，不改变任何映射关系或行状态，不建立 Project Configuration，不执行
实例评价协议，也不产生协议符合性、认证、权威接受、可扩展性或 RQ8 关闭主张。

MethodDefinitionCommit 标识方法契约；独立的 MethodCompatibilityDispositionCommit 标识
受评审处置；ARINC v4.3 发布提交标识被评价的实例内容。这三个身份与未来 v4.3.1 确认合并
不可相互替代。
