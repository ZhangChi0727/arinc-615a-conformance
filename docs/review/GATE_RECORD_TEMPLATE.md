# 中文版

门禁记录必须包含记录 ID、RG0–RG6 门、产物/版本、RB-2026-001-v4.2、主张 ID 和日期；列出评审者及独立性；检查产物完整、上游门通过、风险/偏差可见、复现材料可用，以及适用时序语义、时钟元数据和误差预算齐全。发现按 Must/Should/Nice 记录负责人和处理证据；结论只能为 `APPROVE`、`APPROVE WITH ACTIONS` 或 `REWORK`。

## 评审者与独立性

列出评审者、角色和与作者/产物的独立性声明。

## 进入条件

确认产物已版本化且完整、上游门通过、风险/偏差可见、复现材料可用，并在适用时提供时序语义、时钟元数据和误差预算。

## 发现

每条发现记录 ID、Must/Should/Nice 严重度、内容、负责人和处理证据。

## 剩余风险与行动

记录风险/行动、负责人、期限及其对发布的影响。

## 决定

只能选择 `APPROVE`、`APPROVE WITH ACTIONS` 或 `REWORK`，并记录理由与签字。
