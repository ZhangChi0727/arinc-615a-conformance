\section{Introduction}
\label{sec:intro}

Consider an ARINC~615A-3 UPLOAD in which the tester issues a FIND and then
waits for an acknowledgement. If the acknowledgement is missing, or if a
file-system lock times out, the observation is incomplete rather than a clean
protocol FAIL. A follow-up INFORMATION or a second FIND issued without a
declared observation class can violate the lock and write-then-commit order of
the loading lifecycle~\cite{arinc615a3,arinc6451}. The engineering problem is
therefore not only to generate more tests~\cite{tretmans1996,jia2011,yang2025},
but to keep a candidate set that stays compatible with the observations
actually obtained, to choose one admissible next action, and to stop under a
named class instead of continuing silently.

CL-TAV is specified as that closed loop. Each counted step predicts observation
classes, interprets a raw record under one uncertainty reference, updates a
finite single-fault set \(H\) from the whole compatible history, and selects
one exclusive TEST, Prep, Recover or Admit action. The bound protocol model
remains UPLOAD and INFORMATION. ARINC~645 identity is bound for triggered
leaves; runtime integrity is not established here.

The paper asks three questions. CL-RQ1: can the loop be specified so that a
history-compatible update never restores an eliminated candidate and so that
the one-step choice is a defined operator on the current feasible set?
CL-RQ2: can DETECT and LOCATE be scored with declared denominators, including
unanswered and missing-truth flow, without treating abstention as PASS?
CL-RQ3: can named ablations isolate feedback, Prep/Recover charging and FIND
clock non-waiver without a forbidden waiver algorithm?

The contributions map onto those questions.
\begin{enumerate}
\item C1 (CL-RQ1): under conservative observation and exclusive ownership, the
specified update is monotone and retains every previously eliminated
exclusion. This is a conditional consistency proposition, not a transplanted
general diagnosis theorem~\cite{koehl2023,fraenzle2026,sampath1998}.
\item C2 (CL-RQ1): one prior-free minimax step over the currently feasible and
affordable actions, with explicit error and stop semantics, rather than a
globally optimal policy~\cite{chanthery2009,hu2020,miao2025}.
\item Evaluation protocol (CL-RQ2, CL-RQ3): four comparison arms and three
registered families (DETECT, LOCATE, ABLATION) with finite populations and
missing/censoring rules. Aviation loading work supplies context, not executed
615A evidence~\cite{chanthery2019,efkemann2011,sartaj2021,marques2021}.
\end{enumerate}
