\begin{abstract}
This supplement records the accepted core mechanisms and the S0--S10 duty map
for the TAES first draft. It does not change ALG-CLTAV-01 semantics and does
not report experiments.
\end{abstract}

\section{Scope}
Paper Algorithm~1 is ALG-CLTAV-01. Paper-facing Algorithms~2--4 below are
ALG-CLTAV-05, ALG-CLTAV-06 and ALG-CLTAV-07. Wrappers ALG-CLTAV-02/03/04 and
typed records remain in the repository algorithm package; they are not a
second contribution. Chinese S0--S10 glosses stay in the repository wrapper
and are not copied here.
