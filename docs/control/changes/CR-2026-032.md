|---|---|
| Change class | Pre-run registration amendment; no run; no confirmatory data |
| Base | main `e9871451ef1bf69c65fec992d02860c148a970f9` (registration v1 frozen) |
| Predecessors | CR-2026-030 / DD-054; CR-2026-031 / DD-055 |
| Decision | DD-056 |
| Authorization | User ruling 2026-11-19: score against expected behaviour; hard cases count in the primary contrasts |
| Candidate disposition | Same Draft PR as CR-2026-031; independent DM review required; freeze on merge. CI is not approval. |

## Reason

Registration v1 scored primary metrics only on units whose truth is already determined, and therefore excluded from the primary contrasts the 8 units that are endpoint cases (`HC-FIND-ENDPOINT`, T3 truth unresolved) and short-window LATE vs ABSENT indistinguishability (`HC-LATE-ABSENT-SHORT-WINDOW`, E3 unresolved equivalence). Those units are the hard cases the design added in order to distinguish the arms; excluding them contradicts the design purpose. Unresolved truth is not the same as having no correct behaviour: the correct behaviour of these units can be fixed before any run. The amendment occurs before any cell has run; nobody has seen any confirmatory result, so it is not post-hoc selection.

## Amendment

- New registration file `configs/research/cltav_confirmatory_registration_v2.json` supersedes v1; v1 is retained and labelled as superseded before any run.
- New `configs/research/cltav_confirmatory_expected_behaviour_v1.json`: pre-registers, for every unit, a set of acceptable verdicts and a candidate-set rule (mapped to parent hypotheses).
  - Ordinary fault units: acceptable verdicts [FAIL]; candidate set equals the singleton true parent hypothesis.
  - Endpoint units: acceptable verdicts [INCONCLUSIVE] (C1 interval-overlap rule); candidate set equals {h_normal, late parent}.
  - Short-window units: acceptable verdicts [FAIL]; candidate set equals {late parent, absent parent}.
  - Invalid-observation units: the observation is defective, not an IUT fault; acceptable verdicts are every pipeline verdict except FAIL and PASS; the candidate set must not be a singleton IUT fault.
  - h_normal units (including near-boundary normal and LUR-ACK timing perturbations): acceptable verdicts [INCONCLUSIVE, PASS]; the candidate set must retain h_normal. They remain in the descriptive false-fail share as well.
- Primary metrics become: M-DETECT-CORRECT (verdict is in acceptableVerdicts) and M-LOCALISE-CORRECT (the candidate rule holds of the parent-mapped final set).
- Primary contrasts, tests, multiplicity and stopping rules are unchanged: H1 is CL-LOOP vs CL-T on M-DETECT-CORRECT, H2 is CL-LOOP vs CL-TA on M-LOCALISE-CORRECT; exact two-sided McNemar, Holm correction, familywise α = 0.05; all 312 cells run once, no interim look.
- No unit is excluded except an infrastructure MISSING cell. An UNDEFINED-OUTCOME cell is scored from the arm run record, with a null verdict counted as correct only when acceptable verdicts exclude FAIL and PASS.
- Registration v2 records the SHA-256 of every hashed file (including the expected-behaviour table and the two scripts). The run commit is this PR's merge commit.

## 原因

登记 v1 的主指标只在真值已确定的单元上计分，因此把端点情形（`HC-FIND-ENDPOINT`，T3 真值未决）和短窗下迟到与缺失不可区分的情形（`HC-LATE-ABSENT-SHORT-WINDOW`，E3 未决等价）共 8 个单元排除在主对比之外。这些单元正是设计中为区分实验臂而加入的难例，排除它们与设计目的相矛盾。真值未决并不等于没有正确行为：这些单元的正确行为可以在运行前确定。修订发生在任何单元格运行之前，没有人看过任何确认性结果，因此不构成事后选择。

## 修订内容

- 新登记文件 `configs/research/cltav_confirmatory_registration_v2.json` 取代 v1；v1 保留，标注为运行前被取代。
- 新增 `configs/research/cltav_confirmatory_expected_behaviour_v1.json`：为每个非 h_normal 单元预先登记期望判定与期望候选集（映射到父假设）。
  - 普通故障单元：期望 FAIL，期望候选集为唯一的真实父假设。
  - 端点单元：期望 INCONCLUSIVE（C1 区间部分重叠规则），期望候选集同时含 h_normal 与迟到假设。
  - 短窗单元：期望 FAIL，期望候选集同时含迟到与缺失假设。
- 主指标改为：M-DETECT-CORRECT（判定等于期望判定）与 M-LOCALISE-CORRECT（最终候选集等于期望候选集）。
- 主对比、检验、多重性与停止规则不变：H1 为 M-DETECT-CORRECT 上 CL-LOOP 对 CL-T，H2 为 M-LOCALISE-CORRECT 上 CL-LOOP 对 CL-TA；精确双侧 McNemar，Holm 校正，族系 α = 0.05；312 格各运行一次，无中期查看。
- 登记 v2 记录所有被哈希文件（含期望行为表与两个脚本）的 SHA-256，运行提交为本 PR 的合并提交。
- 不再排除任何单元（基础设施故障 MISSING 除外）。期望行为允许一组可接受判定，并按候选集规则计分：
  - 无效观测单元（`HC-INVALID-OBS-JITTER`）：观测本身有缺陷，不是 IUT 故障；可接受判定为除 FAIL 与 PASS 之外的判定，候选集不得定位为单一 IUT 故障。
  - h_normal 单元（含近边界正常单元与 LUR-ACK 时序扰动）：可接受判定为 PASS 或 INCONCLUSIVE，候选集须保留 h_normal；同时仍作为误报率的描述性统计。
- 评估器给出未定义判定（UNDEFINED-OUTCOME）的单元格不剔除：按实验臂运行记录计分，判定视为空，仅在可接受判定不含 FAIL 与 PASS 时计为正确。
