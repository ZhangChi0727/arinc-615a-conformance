## Why this is required before M2 final approval

Independent visual check of 615A-3 PDF p.85 records LUR field prose at CRS-M1-00143
(clause 6.4.4). Frozen M1 Table 6.4.4-1 (CRS-M1-00309–00315) records those fields as
LUI. Shared nouns HEADER-FILE and LOAD-PART-NUMBER are not enough to emit active
665 edges. M2 therefore stopped those edges (OPEN-M1-CORRECTION). That stop is
correct and is not closure.

UPLOAD field constraints FC-LUI-FIELD-* for CRS-M1-00309–00315 currently copy the
frozen LUI identity. They must not be treated as verified LUR predicates, and they
must not be used as the sole basis for an RG1/RG2 APPROVE of this M2 candidate.
M2 does not silently overlay a second CRS authority.

This CR is one authorization request with two pending items. They may be
authorized together or separately. Neither item is executed until authorized.
Remaining M2 work is not “only waiting for this authorization”: modeled-path
Musts stay in the M2 candidate, and this request does not close them.

Correct Table 6.4.4-1 protocol-file identity LUI→LUR if that is the accepted

  REF-A1-00315-BLOCKED-BY-FILE-IDENTITY.
- Action: M1-FILE-IDENTITY-6-4-4 stays OPEN-M1-CORRECTION until the successor

## Pending item B — CRS-M1-00365 WRQ actor

Independent visual check of §6.3.2 chart A reads Data Loader WRQ of LUR,
Target Hardware ACK, Data Loader DATA. Frozen CRS-M1-00365 records Target Hardware
as the WRQ actor. The M2 machine follows the TFTP-write / visual direction. That
actor mismatch is recorded as OPEN-M1-CORRECTION on the sequence edge; it is not
a rewrite of M1 bytes.

Affected identifiers:

- Requirement: CRS-M1-00365.
- Refinement: REF-SEQ-00365-WRQ-ACTOR.
- Blocking input: SEQ-LUR-WRQ-ACTOR.

## 为何必须在 M2 最终批准前处理

对 615A-3 PDF 第 85 页的独立目视核对显示 CRS-M1-00143（条款 6.4.4）为 LUR 字段
说明。冻结 M1 表 6.4.4-1（CRS-M1-00309～00315）将这些字段记为 LUI。共享名词
HEADER-FILE 与 LOAD-PART-NUMBER 不足以发出活动 665 边。M2 因此停线
（OPEN-M1-CORRECTION）。该停线是正确行为，不是关闭。

UPLOAD 字段约束 FC-LUI-FIELD-*（CRS-M1-00309～00315）目前复制冻结的 LUI 身份。
不得把它们当作已核实的 LUR 谓词，也不得仅凭它们对当前 M2 候选给出 RG1/RG2
APPROVE。M2 不静默覆盖第二套 CRS 权威。

本 CR 是一份授权请求，含两项待授权事项。两项可一并授权，也可分开授权。
任一事项在获授权前均不执行。剩余 M2 工作不能写成“只等本授权”：已建模路径上的
Must 仍在 M2 候选中，本请求不关闭它们。

- 行动：在后继输入获授权并被独立接受前，M1-FILE-IDENTITY-6-4-4 保持
