## Objective

Provide editable, reproducible Draw.io redraws for the nine controlled
`FIG-CL-TAV-*` PlantUML views while preserving their scientific and engineering
meaning. Improve layout and publication readability without creating a second
algorithm, architecture, protocol model, result, or authority.

## Controlled implementation

- PlantUML remains semantic authority; the manifest is a hash-bound derived
  inventory and each `.drawio` file remains `DRAFT-REDRAW`.
- `UTF8-LF-v1` canonical identity makes CRLF/LF checkout conversion equivalent
  while detecting content changes.
- Every title, object, relation, and interpretation note has a finite source
  binding. Object parents and relation endpoints are repeated in those bindings
  so coordinated manifest/XML topology drift fails closed.
- The checker validates actual vertex/edge flags, unique IDs, parent boundaries,
  endpoints, labels, roles, arrow polarity, guard references, and undeclared
  rendered cells.
- Repository-relative ordinary-file paths are mandatory. Absolute, drive,
  traversal, backslash, symlink, junction and reparse escapes are rejected.
- Nine-file generation performs full preflight, stages on the repository volume,
  and restores prior bytes if installation fails.

## Semantic corrections

FIG-CL-TAV-05 routes confirmed-not-sent, unknown-effect, preparation error and
unconfirmed Recover through S7; only confirmed Recover reaches the sole S8
KNOWN writer; valid TEST/Prep advances to S9; empty TEST selection is a named
specification error. FIG-CL-TAV-06 sends protocol observation to Msess before
analysis. FIG-CL-TAV-07 checks retry cap first, retains the complete A4/A5
guards, separates confirmed-not-sent from unknown-effect, and displays the four
ErrorHandle witnesses. These are faithful redraw corrections, not changes to
the controlled algorithm.

## Acceptance

Acceptance requires the shared checker to pass from both repository and
research-environment entry points; mutation, source-binding, line-ending, safe
path, no-partial-write and rollback tests; successful SVG/PDF export; visual
inspection of all nine previews at declared final width; repository-wide gates;
final-head CI; and independent human review. Reader SVG replacement and
manuscript promotion are separate human-controlled actions.

## Non-authorizations

This CR does not authorize PlantUML semantic changes, algorithm/interface edits,
reader-SVG replacement, experimental execution or results, baseline/tag,
submission, merge, capability, Configuration, conformance, certification, or
independent approval.

# 中文版

# CR-2026-020——保持语义的 CL-TAV 模型图重绘工作流

## 目标

为九张受控 `FIG-CL-TAV-*` PlantUML 视图提供可编辑、可复现的 Draw.io
重绘，在不产生第二套算法、架构、协议模型、结果或权威的前提下改善布局和论文可读性。

## 受控实现

- PlantUML 保持语义权威；manifest 只是散列绑定的派生清单，所有 `.drawio`
  均保持 `DRAFT-REDRAW`。
- `UTF8-LF-v1` 令 CRLF／LF 签出转换等价，同时仍检测内容变化。
- 每个标题、对象、关系和解释注记均有有限来源绑定；对象父边界和关系端点在绑定中
  重复记录，使 manifest 与 XML 协同漂移也会失败。
- 检查器验证真实顶点／边标志、唯一 ID、父边界、端点、标签、角色、箭头极性、
  guard 引用及未声明可见单元。
- 路径必须是仓库相对的普通文件；拒绝绝对路径、盘符、遍历、反斜杠、符号链接、
  junction 与 reparse 逃逸。
- 九图生成先完成全批预检，在仓库卷内暂存，安装失败时恢复全部原字节。

## 语义修正

FIG-CL-TAV-05 将 confirmed-not-sent、unknown-effect、准备错误和未确认 Recover
统一送入 S7；只有已确认 Recover 才进入唯一的 S8 KNOWN 写入点；有效 TEST／Prep
进入 S9；空 TEST 选择为具名规格错误。FIG-CL-TAV-06 先把协议观测送回 Msess，
再进入分析。FIG-CL-TAV-07 先检查重试上限，保留完整 A4／A5 guard，区分
confirmed-not-sent 与 unknown-effect，并展示四个 ErrorHandle 见证。这些仅修正
重绘忠实度，不改变受控算法。

## 验收

验收要求：仓库与研究环境入口均通过共享检查器；通过变异、来源绑定、换行、
安全路径、无部分写入及回滚测试；SVG／PDF 导出成功；九张预览按声明最终宽度完成
目检；全仓门禁、最终 Head CI 与独立人工评审通过。替换 reader SVG 和稿件晋级是
另外的人工受控动作。

## 未授权事项

本 CR 不授权 PlantUML 语义更改、算法／接口编辑、reader SVG 替换、实验执行或
结果、baseline／tag、投稿、合并、能力、Configuration、符合性、认证或独立批准。
