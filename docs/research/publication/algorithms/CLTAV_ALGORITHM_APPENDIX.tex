\section*{Appendix A. Typed records and symbols}
\label{app:cltav-types}

Records are explicit. An optional field is a tagged alternative, never an
uninitialized variable; \texttt{NONE} (absent) differs from a tagged \emph{false}
and from an empty set.

\tnoindent Distinct concepts that must not be conflated: an unevaluated
confirmation (NOT-EVALUATED) is not an evaluated \emph{false}; no observation is
not a legitimate-but-empty compatibility class; \texttt{ERROR} is not an IUT
\texttt{FAIL}; an unknown summary is not the old summary. $H$ and $\eta.H$ are one
logical candidate object; \texttt{qUsedAtSelect} is not the post-effect
\texttt{currentSummary}.

\section*{Appendix B. Coordination wrappers (S2, S6, S7--S8)}
\label{app:cltav-coordination}

\textsc{PredictCurrent} (ALG-CLTAV-02, S2) branches on the backend tag before any
projection, so a \texttt{PredictionGapError} never becomes an empty class
collection; the gap stays TEST-scoped and does not by itself block eligible
Prep/Recover. \textsc{InterpretOutcome} (ALG-CLTAV-03, S6) initializes a total
Outcome, calls the timed-observation kernel (ALG-CLTAV-06) and the existing
confirmation interface, and writes nothing. \textsc{ResolveOutcome} (ALG-CLTAV-04,
S7--S8) returns a total Resolution: an ERROR/unknown outcome returns
\texttt{RETRY}, only a confirmed Recover returns \texttt{COMMIT}, and the retry cap
returns \texttt{STOP} (Stop-Error, not Stop-Budget). S8 is the sole writer of
KNOWN; S9 is the sole commit of the confirmed successor summary. No module path
starts the next prediction after a return; only S9 does.

\section*{Appendix D. Unresolved computation kernels and successor gates}
\label{app:cltav-kernels}

Control logic, call order, state reads/writes, budget, return values and error
branches are fully specified. The internal solution techniques remain open and
are abstracted by named contracts; no probability default, HMM/DTMC/Bayesian
kernel or continuous-time discrete grid is introduced.

\begin{table}[H]
\centering
\small
\begin{tabular}{@{}p{3.4cm}p{4.6cm}p{3.4cm}p{3.6cm}@{}}
\hline
Module & Abstract kernel & Input / output / failure & Successor gate \\
\hline
PredictCurrent & finite conservative observation abstract and partition & classesByTest or GAP & estimator/partition algorithm \\
IF-HIST-UPDATE & whole-history compatible-state representation and solver & snapshot + $I_z$ $\to$ next history; version conflict is a spec error & state/clock representation and solver \\
InterpretTimedObservation & event collection and clock error budget & record $\to$ TimingResult; invalid measurement is ERROR & collectors and timestamp handling \\
InterpretOutcome & successor-summary confirmation & record + $\xi$ $\to$ Outcome & protocol confirmation contract \\
IF-PREP-RECOVER & device recovery & returns values only & protocol/device recovery steps \\
IF-EQUIV & provable equivalence decision & established or unknown & optional proof algorithm; not required this round \\
ExecuteAndRecord & protocol execution adapter, timeout, I/O & admitted action $\to$ ExecutionResult & protocol adapter and I/O \\
\hline
\end{tabular}
\end{table}

Successor order: development-ready requirements/interface acceptance $\to$ core
algorithm selection/implementation $\to$ component verification $\to$
configuration and experiment gates $\to$ confirmatory experiment. None of these
backends is implemented here. Specification logic is reviewable from this
package; a stub walk-through is reproducible from the bounded session-loop spec;
the real tool and confirmatory experiment are not implemented. Wrapper code and
finite witnesses are not performance evidence for the algorithm.
