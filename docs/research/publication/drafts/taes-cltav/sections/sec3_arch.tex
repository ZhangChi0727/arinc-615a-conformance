\section{System Engineering and Verification Architecture}
\label{sec:arch}

Protocol conformance requirements, tool requirements and experiment
requirements stay in separate layers. The protocol CRS constrains legal
stimuli, observable events and timing contracts. It does not, by row count,
prove that a verification method works. A representative chain is source clause
\(\to\) obligation \(\to\) observation/verdict contract \(\to\) method
interface. SysML views in the repository are notation-based; executable or
complete metamodel conformance is not claimed.

Two machines must not be merged. The session machine \(M_{\mathrm{sess}}\)
selects from \(S\subseteq A(q)\), charges once, updates \(H\) and returns a
named stop. The protocol machine \(M_{\mathrm{prot}}\) is the bound UPLOAD and
INFORMATION black box. An Execute step of \(M_{\mathrm{sess}}\) applies a
stimulus to \(M_{\mathrm{prot}}\) through declared ports and reads \(I_z\).
That association is not a cross-machine state transition.
