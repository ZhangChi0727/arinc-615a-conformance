\section{CL-TAV Method}
\label{sec:method}

Algorithm~\ref{alg:cltav-01} is the top-level session. Each iteration checks
named stops, predicts, selects and admits one action, freezes a snapshot
including \(U\), charges \(\Gamma\) once, interprets the raw record, resolves
the outcome, and, when the interpreted set is valid, commits a compatible
update. Wrappers and typed records are in the supplement. Figure~\ref{fig:loop}
shows the same control path: \texttt{CONFIRMED-NOT-SENT} and
\texttt{UNKNOWN-EFFECT} act on the observation quality \(q\), not on \(H\).

\subsection{Definitions and assumption}

\begin{definition}[Conservative observation]
\label{def:cons-obs}
An observation is admitted only as a raw record together with a declared
completeness class. Missing, reordered or time-skewed events are not repaired
into extra exclusions. An empty interpreted set \(I_z=\emptyset\) leaves \(H\)
unchanged.
\end{definition}

\begin{definition}[Exclusive ownership]
\label{def:own}
Only the kernel writes \(H\), \(\Gamma\), \(\eta\) and \(U\). Evaluator truth
is not a session input. At most one of TEST, Prep or Recover is selected at a
step. At most one named stop class is returned.
\end{definition}

\begin{assumption}[Exclusive resource mode]
\label{ass:budget}
A session is in exactly one mode, \(\mathrm{BUDGET}(c_{\min},B)\) or
\(\mathrm{ROUNDS}(K_{\max})\), never both. Every counted action consumes a
strictly positive resource quantum in BUDGET or exactly one round in ROUNDS.
Retry caps are not a second budget.
\end{assumption}

\subsection{Update and selection}

With nonempty interpreted set \(I_z\subseteq H\),
\begin{equation}
\label{eq:update}
H^{+} \;=\; I_z \subseteq H,
\end{equation}
and \(H^{+}=H\) when \(I_z=\emptyset\). Selection is the specified one-step
rule on the current feasible, affordable set \(A(H,\Gamma)\):
\begin{equation}
\label{eq:select}
a^{\star} \in \arg\min_{a\in A(H,\Gamma)} \max_{h\in H} c(a,h;\Gamma).
\end{equation}
If \(A(H,\Gamma)=\emptyset\), the session takes the named stop of
Table~\ref{tab:stops} rather than a silent continue. The exclusive resource
invariant is
\begin{equation}
\label{eq:budget}
\bigl(\mathrm{BUDGET}(c_{\min},B)\ \mathrm{xor}\ \mathrm{ROUNDS}(K_{\max})\bigr)=1.
\end{equation}

\subsection{Propositions}

The five retentions below are the accepted method statements R1--R5. They are
conditional on Definitions~\ref{def:cons-obs}--\ref{def:own} and, for
termination, Assumption~\ref{ass:budget}. They are not a new general diagnosis
theorem~\cite{koehl2023}.

\begin{proposition}[Monotonicity, R1]
\label{prop:mono}
Every committed update satisfies \(H^{+}\subseteq H\).
\end{proposition}
\begin{IEEEproof}
Equation~\eqref{eq:update} sets \(H^{+}=I_z\subseteq H\) when \(I_z\) is
nonempty and \(H^{+}=H\) when \(I_z=\emptyset\). In both cases
\(H^{+}\subseteq H\).
\end{IEEEproof}

\begin{proposition}[Retention, R2]
\label{prop:retain}
A candidate eliminated from \(H\) never re-enters. Hence C1 holds under
Definitions~\ref{def:cons-obs}--\ref{def:own}.
\end{proposition}
\begin{IEEEproof}
If \(h\notin H\), then every later nonempty \(I_z\) is formed inside the
then-current \(H\), so \(h\notin I_z=H^{+}\). An empty \(I_z\) does not change
\(H\). Exclusive ownership forbids any other write to \(H\).
\end{IEEEproof}

\begin{proposition}[Exclusive named stop, R3]
\label{prop:stop}
When the session stops, it returns exactly one class from
Table~\ref{tab:stops}.
\end{proposition}
\begin{IEEEproof}
Resource-stop and equivalence contracts return a single named class or
\texttt{undecided}. Admit and post-update stops are exclusive by
Definition~\ref{def:own}. Algorithm~\ref{alg:cltav-01} returns through
\textsc{Finish} on that class and has no silent-continue branch after a named
stop.
\end{IEEEproof}

\begin{proposition}[Finite termination, R4]
\label{prop:term}
Under Assumption~\ref{ass:budget} every session reaches a named stop after
finitely many counted steps.
\end{proposition}
\begin{IEEEproof}
The remaining budget (resp.\ remaining rounds) is a nonnegative integer. Each
counted action strictly decreases that integer. Named stops are the only
exits, and Proposition~\ref{prop:stop} forbids silent continuation. A strictly
decreasing nonnegative integer reaches zero, which is Stop-Budget /
Stop-Resource, unless an earlier named stop has already fired.
\end{IEEEproof}

\begin{proposition}[Specified one-step minimax, R5]
\label{prop:c2}
Equation~\eqref{eq:select} is a total named operator on the finite set
\(A(H,\Gamma)\): it returns a least element, or a named stop if the set is
empty. This is C2 as specified, not a global optimality theorem.
\end{proposition}
\begin{IEEEproof}
\(H\) and the action alphabet are finite, so \(A(H,\Gamma)\) is finite. A
finite nonempty set of real costs has a least element; any tie is broken by
the accepted deterministic order. The empty-set case is a named stop by
Table~\ref{tab:stops}. No claim is made about policies that look beyond the
current step.
\end{IEEEproof}
