## Objective and controlled scope

Record U2–U4 and a DRAFT confirmatory design for the local simulated IUT:
parameterised faults and multiple base scenes as the variation source (not N
repeats, not unseeded randomness); harder in-domain cases declared in the
catalogue and visible to arms only through protocol events; retain the R1 rule
(mixed set containing `h_normal` with no T5 interval → INCONCLUSIVE). Provide
feasibility hooks so faults change only timing, presence or order. Do not run a
census or confirmatory experiment. Do not close DEC-CLOCK, DEC-EQUIV,
DEC-SAMPLE, DEC-RESOURCE or DEC-TRUTH. User decision S1: algorithm-visible
records expose `observationInterval` only (tick ± ε plus jitter). LATE /
in-window / INCONCLUSIVE follow the existing T5 interval rule. This proposal
implements DEC-CLOCK option C1 as that subset/disjoint/overlap rule; DEC-CLOCK
itself remains OPEN. `FIND-ANSWER-BOUNDARY` is an observation class, not a
new protocol event name. Pilot artefacts were produced under the pre-S1
tick-visible interface and are not regenerated.

用户裁决 S1：臂只见观测区间，按既有 T5 区间规则判定；本提案按 C1 子集规则
实现可见接口，DEC-CLOCK 仍 OPEN。试点产物在旧接口下产生，本次不重跑。
