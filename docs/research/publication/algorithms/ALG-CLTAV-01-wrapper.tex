\section*{Chinese step groups (same process, not a second program)}
\begin{itemize}
  \item \texttt{S0}: $\Gamma$ 为唯一状态源；$q$ 是 $\Gamma.\mathrm{currentSummary}$ 的别名，$qStatus$ 只记录该摘要是否已知；retry／$R_{\max}$ 分别是 $\mathrm{retryCount}$／$\mathrm{retryCap}$ 的别名；初始化 $\eta$、$H_0$ 与 retry。
  \item \texttt{S1}: 停止／错误优先门；已决定的 A2--A5 或 P1--P5 立即返回。
  \item \texttt{S2}: 选择前预测（\texttt{ALG-CLTAV-02}）；PredictionGapError 只关掉 TEST 评分；UNKNOWN 且 Recover 仍合格时不得挡合法恢复。
  \item \texttt{S3}: 互斥选择 TEST minimax／Prep／Recover／Admit；空 TEST 集不得 $\arg\min$；空 $\mathcal{C}$ 不阻止合格 Recover。选择后、任何写接口之前冻结 $\textit{qUsedAtSelect}$、历史版本、预测类与动作身份。
  \item \texttt{S4}: 一次计费；重试上限不是预算耗尽。决策索引 $k$、计费次数与 retry 彼此不同。
  \item \texttt{S5}--\texttt{S6}: 执行与解释返回效果类（\texttt{ALG-CLTAV-03}）；正常解释还显式返回后继摘要是否确认。\texttt{CONFIRMED-NOT-SENT} 绕过解释与 Prep 确认，不把它和 \texttt{UNKNOWN-EFFECT} 合成同一种未知。
  \item \texttt{S7}--\texttt{S8}: 结果处置（\texttt{ALG-CLTAV-04}）；prepErr、\texttt{UNKNOWN-EFFECT}、后继摘要未确认的 Prep，以及目标未确认的 Recover，均将 $\eta$ 标为保守未知并清除 $q$；\texttt{CONFIRMED-NOT-SENT} 保持 $q$ 与相容历史并仍计重试。达 $R_{\max}$ 返回 Stop-Error。
  \item \texttt{S9}: 历史更新读选择时快照 $\textit{qUsedAtSelect}$ 与单独的已确认 $\textit{postSummary}$，不读效果后的摘要；仅在 `qStatus` 为 KNOWN 且后继摘要确认时提交 $\Gamma.\mathrm{currentSummary}$。
  \item \texttt{S10}: 互斥 P1--P5；未停止则下一轮从 S1 继续。未确认恢复回边在 S7，不代替这条正常循环。
\end{itemize}
Stop-645 在本增量之后表示仍未在能力/实现层关闭的具名 645 依赖义务，不是“645 文件缺失”。
