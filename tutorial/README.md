# Tutorial and Reproduction Path

Tutorials translate the frozen method and released engineering instrument into
reproducible learning and operating procedures.

Planned path:

1. UDP/TFTP foundations;
2. ARINC 615A roles, services, and observable session behavior;
3. minimal ARINC 665/664 constraints used by the scoped VCs;
4. read an applicability declaration and CRS entry;
5. execute one VC and interpret all four verdicts;
6. inspect its evidence manifest;
7. reproduce a coverage or mutation result without overstating the claim.

Tutorials do not define normative requirements or alter the methodology. They
link to controlled artifacts and record the release version they demonstrate.
