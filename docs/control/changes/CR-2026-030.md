## Registration content

- Registration file: `configs/research/cltav_confirmatory_registration_v1.json`, recording the
  base-commit SHA and the SHA-256 of the listed config files.
- Cells: 78 units × 4 arms = 312 cells, one run per cell; arms see observation intervals only.
- Primary metrics: detection (M-DETECT) and localisation (M-LOCALISE). Secondary metrics:
  false-fail rate, INCONCLUSIVE share, rounds consumed, and stop class; descriptive only.
- Primary contrasts: H1 detection CL-LOOP vs CL-T; H2 localisation CL-LOOP vs CL-TA. Both are
  exact two-sided McNemar tests on same-unit pairs, Holm-corrected, familywise α = 0.05.
- Stopping rules: run all 312 cells once; no interim looks, no early stopping. An infrastructure
  failure is re-run once at the same commit; if it fails again it is recorded as MISSING and
  excluded from both arms of that pair.
- After freeze, any addition, removal or redefinition requires a new CR, and later analysis is
  labelled exploratory. Pilot data must not be reused.
- Known risk: the pilot showed a ceiling effect; if discordant pairs are few, H1/H2 may be
  non-significant, and this is reported as is.

## 登记内容

- 登记文件：`configs/research/cltav_confirmatory_registration_v1.json`，记录基点提交 SHA 与所列配置文件的 SHA-256。
- 单元格：78 个单元 × 4 臂 = 312 个单元格，每格运行 1 次；臂只看到观测区间。
- 主指标：检测（M-DETECT）与定位（M-LOCALISE）。次指标：误报率、INCONCLUSIVE 比例、消耗轮数、停止类别，仅作描述。
- 主对比：H1 检测 CL-LOOP 对 CL-T；H2 定位 CL-LOOP 对 CL-TA。均为同单元配对的精确双侧 McNemar 检验，Holm 校正，族系 α = 0.05。
- 停止规则：312 格全部运行一次；无中期查看、无提前停止。基础设施故障在同一提交重跑一次，仍失败则记为 MISSING 并从该配对两侧剔除。
- 冻结后任何增删或重定义都须经新 CR，且其后分析标注为探索性。试点数据不得复用。
- 已知风险：试点存在天花板效应；若不一致配对很少，H1／H2 可能不显著，照实报告。
