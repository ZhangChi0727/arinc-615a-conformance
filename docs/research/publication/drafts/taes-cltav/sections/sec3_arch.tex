\section{System Engineering and Verification Architecture}
\label{sec:arch}

Figure~\ref{fig:arch} is the architecture used in this paper. Protocol and
uncertainty objects sit above a kernel that owns the candidate set \(H\), the
resource context \(\Gamma\) and the observation map \(\eta\). Named contracts
on that kernel appear as figure labels; the supplement maps them to repository
identifiers. Only a raw record, with its declared completeness, returns from
execution into history update. Evaluator truth never enters the session.

The layering responds to two aviation lessons without importing their
authority. F-LAS shows the usefulness of explicit requirements-to-procedure
traceability for loading identity, integrity, interrupted loading and version
conflict, but its procedures were proposed rather than
executed~\cite{marques2021}. Avionics MBT also makes configuration, model
preparation, simulator and oracle boundaries part of the test
problem~\cite{efkemann2011,sartaj2021}. Accordingly, the protocol register
constrains legal evidence, the tool realizes method contracts, and the
evaluator owns independent truth; none can silently stand in for another.

Two machines must not be merged. The session machine selects from a legal
action set, charges once, updates \(H\) and returns a named stop. The protocol
machine is the UPLOAD/INFORMATION black box. Execute issues a stimulus and
obtains a raw execution record. Interpretation, not the network port, produces
the compatible class \(I_z\) and hypothesis survivors.

\paragraph{Bound objects.}
The operational bound remains ARINC~615A-3 UPLOAD and INFORMATION, with
FIND/SEND/ABORT as UPLOAD operations~\cite{arinc615a3}. ARINC~645-1
SOURCE/SEMANTIC identity is bound only for triggered leaves; runtime 645
capability is not established~\cite{arinc6451}. Hypothesis space \(H_0\) is
finite and single-fault: \(H_0=\{h_{\mathrm{normal}}\}\cup H_{\mathrm{single}}\).
A singleton \(\{h_{\mathrm{normal}}\}\) is not protocol PASS. Tests, Prep and
Recover are exclusive alternatives. Counted actions consume \(\Gamma\) once.

\paragraph{Scope.}
C1 is specified consistency and true-fault retention under R1--R5, not a
general theorem for loss, drift or reordering. C2 is the named one-step rule,
not a globally optimal policy. The manuscript does not claim a full 615A IUT,
certification, or confirmatory measurements.
