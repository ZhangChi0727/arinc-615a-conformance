\section{Experimental Setup and Evaluation Protocol}
\label{sec:setup}

No confirmatory execution is reported. The comparison contract is the existing
experiment plan. Four arms share the same information pool, action pool and
fault domain. Direct numeric comparison is allowed only on the same denominator
and the same charged projection of
\(c=(c_{\mathrm{acq}},c_{\mathrm{comp}},c_{\mathrm{prep}},c_{\mathrm{retry}})\).
Runtime records may retain recovery as a detail, but evaluation folds it into
\(c_{\mathrm{prep}}\) exactly once. Figure~\ref{fig:exp} is the experiment
architecture: E0--E6 are registered experiment steps, not execution evidence.
CL-LOOP is the closed loop under test.

Truth is typed evaluator-only. It never enters selection, prediction, history
update or execute; algorithm-visible references are limited to registered
initial inputs and records produced by that arm's own actions. The all-attempt
ledger retains every registered attempt, including unconfirmed injection,
invalid observation, equivalent or undecided fault, \texttt{ERROR}, abstention
and unconcluded execution. Detection uses a named valid denominator and a
separate answered subset for PASS/FAIL error. Localization uses confirmed
in-domain non-equivalent injections and separately reports
localization-decision coverage, whether the true fault remains or is excluded,
whether an issued singleton is correct, and final \(|H|\). If no attempt is
answered, answered coverage is \(0/N\) for \(N>0\), whereas
answered-conditional error is not applicable. Mutation scores exclude only
confirmed equivalents while equivalent and undecided counts remain
visible~\cite{jia2011,gruen2009}.

DETECT compares miss and refusal under the same detection budget and the T5
oracle; FIND abort does not waive the 2\,s / 3\,s clocks. LOCATE compares
surviving \(|H|\) and true-fault exclusion on confirmed in-domain injections.
ABLATION uses the registered factors: no feedback (CL-T or CL-TA); Prep/Recover
uncharged; interval versus point-timestamp on the same traces with clocks
fixed; and FIND-abort-as-waiver as a forbidden negative control, not an allowed
algorithm. Sample size remains a named gap.

An experimental unit is a unique registered attempt on one base scene, arm and
control/fault construction. Development, pilot and held-out lineages are
disjoint; paired arms require independent reset evidence. When later
measurements exist, interval and effect reporting follows the registered
unit~\cite{arcuri2011}. Clock and error budgets, when frozen, follow the
declared metrology context~\cite{jcgm100,jcgm106}. T5 uses a closed timing
interval: containment is PASS, disjointness FAIL, partial overlap
INCONCLUSIVE.

Rejected updates preserve \(H\) independently of the stop tag; valid empty and
singleton updates force Stop-Empty and Stop-Singleton before later stops. An
\texttt{ERROR}, Stop-Empty, Stop-645, or budget stop cannot manufacture an
answered or singleton-localization decision.

For the registered no-response scenario, the scored trigger is the data loader
receiving a status file that carries an exception delay for the active
operation. A prescribed abort after expiry is a fallback, not a cancellation
waiver of the FIND clocks. Generic request/response suppression remains a
method-only case and is not scored as that scenario.
