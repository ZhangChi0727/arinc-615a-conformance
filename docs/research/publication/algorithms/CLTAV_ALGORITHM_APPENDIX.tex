\section*{Appendix A. Typed records and symbols}
\label{app:cltav-types}

Records are explicit. An optional field is a tagged alternative, never an
uninitialized variable; \texttt{NONE} (absent) differs from a tagged \emph{false}
and from an empty set. Every producer, consumer and sole writer is fixed here.

\noindent Distinct concepts that must not be conflated: an unevaluated
confirmation (NOT-EVALUATED) is not an evaluated \emph{false}; no observation is
not a legitimate-but-empty compatibility class; \texttt{ERROR} is not an IUT
\texttt{FAIL}; an unknown summary is not the old summary. $H$ and $\eta.H$ are one
logical candidate object; \texttt{qUsedAtSelect} is not the post-effect
\texttt{currentSummary}. The action \emph{kind} (TEST/PREP/RECOVER) is separate
from the action \emph{id}; recovery is never recognized by requiring a particular
id string.

\section*{Appendix B. Coordination wrappers (S2, S6, S7--S8)}
\label{app:cltav-coordination}

\textsc{PredictCurrent} (ALG-CLTAV-02, S2) branches on the backend tag before
reading or projecting classes and re-tags a projection that yields no nonempty
class as the same named gap, so a gap never becomes an empty class collection or
a score of zero; the gap stays TEST-scoped and does not by itself block eligible
Prep/Recover. \textsc{InterpretOutcome} (ALG-CLTAV-03, S6) copies the executed
effect and the snapshot kind into a total Outcome, calls IF-OBS-INTERPRET and the
timed kernel ALG-CLTAV-06, and propagates an interpretation ERROR to S7 instead
of a confirmed summary; it writes nothing. \textsc{ResolveOutcome} (ALG-CLTAV-04,
S7--S8) returns a total Resolution initialized from $\Gamma$: an ERROR/unknown or
unconfirmed outcome returns \texttt{RETRY}, a confirmed Recover returns
\texttt{COMMIT} and is the sole writer of KNOWN, a normal TEST/Prep with a valid
observation also commits, and the retry cap returns \texttt{STOP} (Stop-Error, not
Stop-Budget). S9 is the sole commit of the confirmed successor summary, under the
guard enforced by ALG-CLTAV-01. No module path starts the next prediction after a
return; only S9 does.

\section*{Appendix D. Unresolved computation kernels and successor gates}
\label{app:cltav-kernels}

Control logic, call order, state reads/writes, budget, return values and error
branches are fully specified. The internal solution techniques remain open and
are abstracted by named contracts; no probability default, HMM/DTMC/Bayesian
kernel or continuous-time discrete grid is introduced.

\centering

\hline
Module & Abstract kernel & Input / output / failure & Successor gate \\
\hline
PredictCurrent & finite conservative observation abstract and partition & classes or tagged GAP & estimator/partition algorithm \\
IF-HIST-UPDATE & whole-history compatible-state representation and solver & snapshot + $I_z$ $\to$ $H_c,\eta_c$; version/intersection mismatch is a spec error & state/clock representation and solver \\
InterpretTimedObservation & event collection, clock error budget, pairing & ownership + interval $\to$ TimingResult; empty domain is ERROR & collectors and timestamp handling \\
IF-OBS-INTERPRET & correlation, ownership, interval validity, compatible $I_z$ & record $\to$ $I_z$, effect, summary, ownership, interval & collectors and interval solver \\
IF-PREP-RECOVER & device recovery and confirmation & returns values only & protocol/device recovery steps \\
IF-EQUIV & provable equivalence decision & established or unknown & optional proof algorithm; not required this round \\
ExecuteAndRecord & protocol execution adapter, timeout, I/O & admitted action $\to$ ExecutionResult & protocol adapter and I/O \\

{\sloppy Successor order: development-ready requirements and interface
acceptance; then core algorithm selection and implementation; then component
verification; then configuration and experiment gates; then confirmatory
experiment.} None of these
backends is implemented here. Specification logic is reviewable from this
package; a stub walk-through is reproducible from the bounded session-loop spec;
