## Objective and controlled scope

Authorize the E0–E6 experiment pipeline SCENE → INJECT → TRUTH → RUN → COLLECT
→ FILTER → EVAL on the simulated IUT. Walkthroughs WF-NORMAL,
WF-UNCONFIRMED-INJECT, WF-INVALID-OBS, WF-ABSTAIN and WF-EQUIVALENT are
executable tests compared with SYN-* rows through a registered mismatch table.
A VALID candidate set that contains `h_normal` together with other hypotheses
and has no T5 interval is `INCONCLUSIVE` (MET-INCONCLUSIVE; outside
POP-ANSWERED; never PASS or FAIL). WF-ABSTAIN and WF-EQUIVALENT are
ACCOUNTING-REPLAY: SYN-* feed RUN and COLLECT inputs only; FILTER and EVAL
compute validity, outcome, and populations. Metrics follow the
metric dictionary and declared denominators. Truth is read only in EVAL through
TruthCapability. Output is machine-readable run records plus a registration-shaped
pilot config whose N and seeds remain PENDING-PHASE-D. Label SIMULATED-IUT /
PILOT. No manuscript result cell is filled. Phase D remains out of scope.

## Authorized deliverables

- E0 `IF-EXP-SCENE` through E6 `IF-EXP-EVAL` under `src/a615a_sim/evaluator/pipeline/`.
- Executable WF-* tests versus SYN-* expected fields.
- N3: ReferenceSession contacts the IUT only through `environment.execute`.
- N4: absent-answer timing metrics use the observation end, not request tick 0.
- `configs/research/cltav_pilot_registration_shape_v1.json` (not `registration.yaml`).

## Boundaries and non-authorizations

- Does not change `src/cltav_runtime/` semantics, CRS, M2, or algorithm
  interfaces.
- Does not close DEC-IUT, DEC-TRUTH, DEC-CLOCK, DEC-EQUIV, DEC-SAMPLE, or
  DEC-RESOURCE.
- Does not fill PH-RES-* / PH-ABS-RESULT / PH-STAT-N or claim superiority.
- Does not start Phase D, Ready, merge, tags, or protection changes.
- Does not treat SYN-* rows as observed experiment results.

## 目标与受控范围

授权在模拟 IUT 上实现 E0–E6 流水线 SCENE → INJECT → TRUTH → RUN → COLLECT →
FILTER → EVAL。走查 WF-NORMAL、WF-UNCONFIRMED-INJECT、WF-INVALID-OBS、WF-ABSTAIN
与 WF-EQUIVALENT 作为可执行测试，并与 SYN-* 通过已登记差异表比对。含 `h_normal`

MET-INCONCLUSIVE，不进入 POP-ANSWERED，不是 PASS 或 FAIL）。WF-ABSTAIN 与
WF-EQUIVALENT 为 ACCOUNTING-REPLAY：SYN-* 只提供 RUN／COLLECT 输入，FILTER 与
EVAL 自行计算 validity、outcome 与总体。指标按指标字典与声明
分母计算。真值仅在 EVAL 经 TruthCapability 读取。产出机器可读运行记录，以及 N
与种子仍为 PENDING-PHASE-D 的登记形状试点配置。标注 SIMULATED-IUT／PILOT。不填
写稿件结果格。Phase D 仍不在范围。
