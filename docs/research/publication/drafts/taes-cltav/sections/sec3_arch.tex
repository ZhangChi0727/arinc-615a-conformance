\section{System Engineering and Verification Architecture}
\label{sec:arch}

Figure~\ref{fig:arch} is the architecture used in this paper. Protocol and
uncertainty objects sit above a kernel that owns the candidate set \(H\), the
resource context \(\Gamma\) and the observation map \(\eta\). Prediction,
history update, observation interpretation, selection, execution, preparation
and exclusive stop are named contracts on that kernel; the figure labels them
in place. The supplement maps those labels to repository identifiers. Only a
raw record, with its declared completeness, returns from execution into
history update. Evaluator truth never enters the session.

The motivating incomplete observation sits on this figure. A missed FIND
acknowledgement or a lock timeout is an incomplete raw record, not a licence
to issue an unconstrained next action. Marques \textit{et al.} propose
traceable loading requirements and procedures for a future loadable airborne
system, including an exclusive file-system lock and write-then-commit
order~\cite{marques2021}. That survey is engineering context; it is not
executed 615A evidence, and this paper does not execute it.

\paragraph{Bound objects.}
The operational bound remains ARINC~615A-3 UPLOAD and INFORMATION, with
FIND/SEND/ABORT as UPLOAD operations~\cite{arinc615a3}. ARINC~645-1
SOURCE/SEMANTIC identity is bound only for triggered leaves; runtime 645
capability is not established~\cite{arinc6451}. Hypothesis space \(H_0\) is
finite and single-fault: \(H_0=\{h_{\mathrm{normal}}\}\cup H_{\mathrm{single}}\).
A singleton \(\{h_{\mathrm{normal}}\}\) is not protocol PASS. Tests, Prep and
Recover are exclusive alternatives. Counted actions consume \(\Gamma\) once.
Observation map \(\eta\) and uncertainty reference \(U\) are owned inside the
kernel. The implementation status of each named contract is not re-argued
here.

\paragraph{Scope.}
C1 is specified consistency under conservative observation and exclusive
ownership, not a general theorem for loss, drift or reordering. C2 is the
named one-step rule, not a globally optimal policy. The manuscript does not
claim a full 615A IUT, certification, or confirmatory measurements.
