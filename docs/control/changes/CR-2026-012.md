## Why this change exists

PR #14 merged an ordinary two-parent commit whose second parent is the approved M2 Head. That exit is a **bounded M2 model** for UPLOAD and INFORMATION. It is not a development-ready CRS, not Project Configuration, and not protocol conformance.

This CR authorizes a successor increment that:

1. Revises the research method to **CL-TAV** (闭环测试—分析协同验证方法 / Closed-Loop Test–Analysis Verification).
2. Replaces the publication outline with a detailed CL-TAV thesis plan (system-engineering/SysML architecture, mathematical algorithms, comparative experiments, contribution–evidence links).
3. Expands the **protocol** CRS so INFORMATION, UPLOAD, Media Defined DOWNLOAD, Operator Defined DOWNLOAD, FIND, and the corresponding abort/reject/exception/retry obligations are source-audited and semantically reviewable. Network/configuration variants are conditional, not one mixed instance.

The combination of Test and Analysis is **not** claimed as a first invention. Contributions remain propositions to be argued and later evaluated.

This PR must not leave mistranslation or omitted source-explicit obligations “for the next PR.” The successor PR must not redo method planning.

## Scope that is in

- Protocol operations: INFORMATION, UPLOAD, Media Defined DOWNLOAD, Operator Defined DOWNLOAD, FIND, and interrupt/reject/exception/retry obligations that the sources actually state.
- ARINC 665-5 load-data/media-set clauses, 664P2 / 664P3-1 / 664P7, and RFC 768/791/1122/1123/1350/1785/2347/2348/2349: complete applicability audit (applicable / conditionally applicable / justified not-applicable / non-normative / named source block).
- Configuration dimensions kept separate: ordinary Ethernet, Compliant Network, Profiled Network, AFDX. The already-selected Compliant path keeps its instance identity. Other variants may enter **conditional** CRS rows; they do not activate the old instance.
- Exact ARINC 645 limitation: unique algorithm/constant/naming details stay `BLOCKED-SOURCE-645`. Obligations already explicit in 615A/665 remain. Surrogate integrity services may check call/state propagation only.

## Scope that is out

- Codec, protocol engine, executable EFSM, TP/VC, instance Configuration, confirmatory experiments, tags, or a new named baseline.
- Claiming that the merged M2 model covers DOWNLOAD, FIND, AFDX, or Profiled deviations.
- Claiming first/best/significant superiority without literature comparison and evidence.
- Purchasing tools or standards, attaching real equipment, or running live load.

## 为何需要本变更

PR #14 已以普通两父提交合并，第二父为批准的 M2 Head。该出口是 UPLOAD 与 INFORMATION 的**有界 M2 模型**，不是开发就绪 CRS，不是 Project Configuration，也不是协议符合性。

本 CR 授权后继增量：

1. 将研究方法修订为 **CL-TAV**。
2. 用详细 CL-TAV 论文计划替换现有出版大纲。
3. 扩大**协议** CRS，使 INFORMATION、UPLOAD、Media Defined DOWNLOAD、Operator Defined DOWNLOAD、FIND 及来源实际规定的中断／拒绝／异常／重试义务可来源审计且语义可审。网络／配置变体是条件化的，不混成同一实例。

测试与分析的组合**不**被声称首次发明。贡献仍是拟论证、待评价的命题。
