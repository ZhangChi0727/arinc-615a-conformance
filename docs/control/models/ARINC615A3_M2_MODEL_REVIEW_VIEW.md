## Source refinements

- `REF-A1-HEADER-FILE` — `CANDIDATE-REFINEMENT` — UPLOAD LUI header-file name encoding uses the same HEADER-FILE object that 665-5 defines for software-part header files. The edge is limited to that shared object; it does not import 665 media-set or CRC algorithms.
- `REF-A1-LOAD-PART-NUMBER` — `CANDIDATE-REFINEMENT` — LUI table field FIELD-LOAD-PART-NUMBER-NAME and 665-5 load-part-number encoding share the LOAD-PART-NUMBER object used during UPLOAD list transfer.
- `REF-A2-TFTP-OPTION-2347` — `CANDIDATE-REFINEMENT` — 615A 5.3.2.2 requires transferring TFTP options. RFC 2347 is the option-extension mechanism named by P3 for base TFTP. The edge does not activate P3 profiled deviations or claim complete RFC-2347 conformance.
- `REF-A2-NO-RFC-1785-ACTIVE-EDGE` — `NOT-ESTABLISHED-NO-ACTIVE-SOURCE-UNIT` — Inventory of UPLOAD/INFORMATION option units (CRS-M1-00020..00023, 00074, 00075, 00081, 00083) does not name RFC 1785. P7 listings remain with unselected AFDX and do not create an active 615A edge.
- `REF-A2-NO-RFC-2348-NAME` — `NOT-ESTABLISHED-NO-ACTIVE-SOURCE-UNIT` — No inventoried 615A UPLOAD/INFORMATION unit names the blksize option token. Default TFTP block handling remains 615A-defined, not an RFC-2348 edge.
- `REF-A2-NO-RFC-2349-NAME` — `NOT-ESTABLISHED-NO-ACTIVE-SOURCE-UNIT` — 615A exception and DLP timers are protocol parameters, not an identified RFC-2349 timeout/tsize option unit.
- `REF-P2-PHYSICAL-ETHERNET` — `IDENTITY-RECORDED-BEHAVIOR-UNESTABLISHED` — Current Ethernet profile uses P2 for physical/data-link identity. Capability ETHERNET-PHYSICAL-LINK-SEMANTICS remains NOT-ESTABLISHED.
