expiry/no-response comparison uses `>= U_r`. For a closed endpoint it uses
`> U_r`. A nonzero error interval around a nominal response at `U_r` is
INCONCLUSIVE unless the entire possible interval remains inside the allowed
set.

## Four-valued verdict review

- PASS requires established preconditions, valid measurement, valid pairing,
  and complete containment of all possible true values in the allowed set.
- FAIL requires established preconditions, valid measurement, and disjointness
  of all possible true values from the allowed set; no-response FAIL additionally
  requires a still-active obligation and a robustly expired horizon.
- INCONCLUSIVE covers boundary overlap, unresolved preconditions, insufficient
  observation, and a horizon not yet certainly beyond the deadline.
- ERROR covers invalid tools/time sources/timestamp chains/pairing/budgets and an
  empty observation interval caused by a contradictory measurement model.
- No reviewed path silently converts ERROR or INCONCLUSIVE to FAIL or omits it
  from reporting.
