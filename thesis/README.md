# Publication Workspace

| Folder | Use |
|---|---|
| `drafts/` | Manuscript sections |
| `notes/` | Annotated literature and exploratory notes |
| `figures/` | Reproducibly generated publication figures |

Canonical sources:

- method: [`../docs/BASELINE.md`](../docs/BASELINE.md);
- structure: [`../RESEARCH_OUTLINE.md`](../RESEARCH_OUTLINE.md);
- evidence wording: [`../docs/research/CLAIM_EVIDENCE_MATRIX.md`](../docs/research/CLAIM_EVIDENCE_MATRIX.md);
- experiments: [`../docs/research/EXPERIMENT_PLAN.md`](../docs/research/EXPERIMENT_PLAN.md).

Drafts may describe planned methods, but results and conclusions must identify
the supporting artifact version and gate. Keep exploratory results out of
confirmatory result tables unless clearly labeled.
